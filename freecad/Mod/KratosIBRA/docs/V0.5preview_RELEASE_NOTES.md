# V0.5preview Release Notes

Date: 2026-09-26. This preview is based on the V0.2 tag and is published on a separate `release/v0.5preview` branch and `V0.5preview` tag. The V0.2 tag and its historical example remain unchanged.

## Scope

- Units and schema-3 project contracts, separate material/section thickness, and solver-parameter validation.
- Geometric coupling candidates with explicit user decisions; analysis domains, named groups, entity mapping, and FreeCAD document association.
- Inspectable preprocessing, geometry-change invalidation, and explicit rebind guards.
- Reference-configuration pressure and bounded time-amplitude tables.
- Read-only access to Kratos IGA's native `results.vtkhdf`, with displacement-frame display in FreeCAD.
- Three editable end-to-end examples: a single-patch cantilever, a continuous two-patch shell, and a perforated trimmed plate.

## Acceptance record

Target environment: Windows x64, FreeCAD 1.1.3, Python 3.11.9, OCP 7.8.1.1, and Kratos 10.4.3.

- P0-1 through P0-5 passed staged acceptance, including real Kratos initialization/solution, native FreeCAD document save/reopen, and host checks for pressure and time tables.
- P0-6 passed within its revised scope: it reads only native VTKHDF; all three results display in target FreeCAD; wrong-model rejection, isolated runs, and switching a real two-step result were checked. The targeted result-viewer regression recorded 159 passing checks.
- All three P0-7 cases passed project-contract checks, real Kratos numerical checks, and FreeCAD panel load/save/cross-process reopen. The measured maximum displacement was 0.02000000000080121 mm for the single-patch cantilever and 0.1600030769827438 mm for the two-patch shell. The perforated plate's integration area was about 32 mm² and its assembled pressure resultant was about 0.032 N in z.
- The final full backend regression recorded 415 passing tests and 54 skipped; result-viewer work has a separate 159-check targeted regression.

These values describe the shipped examples and executed host checks. They are not general guarantees for arbitrary CAD models or engineering analyses.

## Known limitations

- Results are read only from native Kratos IGA VTKHDF, which cannot recover CAD Face/UV identities. Result viewing adds no run-level input-hash value or manifest; existing project geometry-change invalidation remains in place.
- Penalty-condition RHS is available, but its signed physical-reaction convention is not fully verified; overall equilibrium with penalty conditions is reported as unverified. Solver success or visualization alone does not establish force equilibrium.
- Pressure acts on the reference configuration; follower pressure is unsupported. Automatic unit conversion for rotational coupling currently rejects unsupported configurations.
- Panel data round-trips passed for the three cases. Interactive rebinding after arbitrary geometry edits and visual 3D judgment were outside this case acceptance. Exact nonlinear support reactions and the target C++ condition's internal `diff_phi` value remain unverified.
- Only Windows x64 and the versions above were validated. Independent beams, volumetric parameterization, solid elements, contact, multiphysics, and general trimming-point supports are outside this release.

## Install and preview

Download the source archive attached to this Release, configure the Python 3.11 backend, and install the workbench using the [installation guide](https://github.com/adkl1117/STEP2IBRA/blob/release/v0.5preview/freecad/Mod/KratosIBRA/docs/Installation_en.md). To open an example, select **Open Project** in the workbench panel and choose any `.ibra-project.json` under the installed `examples` directory. **Open Cantilever Example** remains the entry point for the historical V0.2 case.

See the [English user guide](https://github.com/adkl1117/STEP2IBRA/blob/release/v0.5preview/freecad/Mod/KratosIBRA/docs/User_Guide_en.md) for the complete workflow.
