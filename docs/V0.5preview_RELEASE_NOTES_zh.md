# V0.5preview 发布说明

日期：2026-09-26。此版本以 V0.2 标签为基线，在独立的 `release/v0.5preview` 分支和 `V0.5preview` 标签发布。V0.2 标签与其历史算例保持原样。

## 功能范围

- 单位与 schema-3 项目契约、独立材料/截面厚度及求解器参数校验。
- 几何耦合候选与用户确认状态；分析域、命名组、实体映射及 FreeCAD 文档关联。
- 可检查的前处理预览、几何变化失效保护和显式重绑定守卫。
- 参考构形压力与有界时间倍率表。
- 只读读取 Kratos IGA 原生 `results.vtkhdf`，在 FreeCAD 中显示选定步的位移场。
- 三个可编辑的完整算例：单 patch 悬臂、双 patch 连续壳、含孔裁剪板。

## 验收记录

目标环境为 Windows x64、FreeCAD 1.1.3、Python 3.11.9、OCP 7.8.1.1 和 Kratos 10.4.3。

- P0-1 至 P0-5 通过阶段验收；包含实际 Kratos 初始化/求解、FreeCAD 原生项目保存重开及目标宿主压力和时间表检查。
- P0-6 在修订范围内通过：仅读原生 VTKHDF；三个结果可在目标 FreeCAD 显示；错误模型拒绝、独立 run 和两步结果切换已检查。159 项结果查看定向回归通过。
- P0-7 三个算例均通过项目契约、实际 Kratos 数值检查和 FreeCAD 面板载入/保存/跨进程重开。单 patch 悬臂实测最大位移 0.02000000000080121 mm；双 patch 实测最大位移 0.1600030769827438 mm；含孔板积分面积约 32 mm²、压力组装合力 z 分量约 0.032 N。
- 最终完整后端回归记录为 415 项通过、54 项跳过；结果查看方向另有 159 项定向回归通过。

这些数字对应随附案例与已执行的目标宿主检查，不代表对任意 CAD 模型或工程分析的通用保证。

## 已知限制

- 结果只从 Kratos IGA 原生 VTKHDF 读取；该格式不能恢复 CAD Face/UV 对应。结果查看没有新增 run 级输入哈希字段或哈希清单；项目原有几何失效保护仍保留。
- 罚条件 RHS 可读，但其有符号物理反力约定未充分证实；含罚条件的整体平衡显示为未验证。求解成功或结果可视化不能单独证明力学平衡。
- 压力施加于参考构形，不支持随动压力。旋转耦合的自动单位换算目前会拒绝不受支持的配置。
- 三个案例的面板数据往返已通过；任意几何修改后的交互重绑和可视三维判定未纳入这组案例验收。精确非线性支承反力及目标 C++ 条件内部 `diff_phi` 数值也未验证。
- 仅验证 Windows x64 与上述软件版本。独立梁、体积参数化、实体单元、接触、多物理场及一般裁剪点支承不在本版范围内。

## 安装与预览

下载本 Release 的源码压缩包，按[中文安装指南](../freecad/Mod/KratosIBRA/docs/Installation_zh.md)配置 Python 3.11 后端并安装工作台。首次查看算例时，在工作台面板点 **Open Project**，打开安装目录 `examples` 下任意 `.ibra-project.json`。`Open Cantilever Example` 按钮保留给历史 V0.2 算例。

完整操作说明见[中文使用指南](https://github.com/adkl1117/STEP2IBRA/blob/release/v0.5preview/freecad/Mod/KratosIBRA/docs/User_Guide_zh.md)。
