# STEP2IBRA V0.5 Preview — 版本说明与使用说明

版本：0.5.0 · 日期：2026-09-27 · 工作台：**IBRA Preprocessor for Kratos**

[English version](V0_5_RELEASE_NOTES_en.md)

V0.5 将 STEP 曲面几何、材料与截面、分析域、边界及初始条件、接口连接决策、求解与结果查看整合到 FreeCAD 工作台。新增鼠标点选、耦合边隔离显示和悬浮编号查看。本文说明当前预览版的功能与操作，不包含安装步骤。

## 启动与第一个项目

1. 按[安装指南](V0_5_INSTALLATION_zh.md)安装发布包，使用选定的用户目录启动 FreeCAD。
2. 在 FreeCAD 工作台下拉框选择 **IBRA Preprocessor for Kratos**。
3. 使用面板顶部的 **打开项目**；后端设置在 **输出 → 分析与输出**。
4. 推荐打开解压目录中的 `freecad/Mod/KratosIBRA/examples/two_patch/two_patch_shell.ibra-project.json`。

下文路径相对于解压后的发布包；相同算例也会复制到安装后的 `Mod/KratosIBRA/examples` 目录。

## 选择界面语言

面板顶部的 **Interface language / 界面语言** 可选择 **English** 或 **中文**，立即更新按钮、导航、字段、工具提示、悬浮及鼠标逐步提示，并保存选择供下次启动使用。切换保留当前模型、条件草稿、目标与点选阶段，不改变 FreeCAD 的全局语言。技术变量、文件路径、编号及自定义名称保留原值，后端原始日志和数值诊断保留技术原文。本文为便于与英文版本对照，部分操作使用英文按钮名称；中文界面显示对应译名。

## V0.5 的主要变化

- 单位、材料与截面：保存明确的单位体系、弹性参数、密度和正值厚度，支持显式数值换算。
- 接口连接：区分候选、确认与排除状态；由使用者选择连接意图和方法，几何邻接本身不等同于力学连接。
- 分析域与命名组：控制参与计算的曲面，以命名几何集合复用条件目标；支持 FreeCAD 文档关联与受控重新绑定。
- 可检查的前处理：查看支承、载荷、曲面参数方向、参考法向、材料截面与离散信息。
- 压力与时间表：支持标量参考法向压力、方向翻转及分段线性幅值表。
- 求解及结果：导出独立计算目录，初始化或运行 Kratos，读取原生 `results.vtkhdf` 并绘制位移与变形帧。
- 鼠标操作：普通条件左键点选、中键确认；接口按曲面、曲面、耦合边顺序选择；面板持续显示下一步提示。

## 查看几何、编号与耦合边

在 **Geometry** 页的 **Hover audit** 下拉框选择查看模式：

| 模式 | 鼠标悬浮时显示 |
| --- | --- |
| Edge / Patch / Coupling (all) | 当前注册实体的类型和编号 |
| Edge (one-sided boundary) | 普通单侧边界 Edge 编号 |
| Patch (surface) | 曲面 Patch 编号 |
| Coupling (interface edge) | 候选接口 Coupling 编号 |

这些编号来自当前项目的几何映射，不能用 FreeCAD 的任意 `FaceN` / `EdgeN` 编号替代。

在 **Interfaces** 页点击 **只显示耦合边**，可以临时只显示耦合边；再次点击恢复之前的可见性。点选接口表格中的行可高亮对应边，必要时会临时显示隐藏的接口。隔离显示不修改分析域或接口决策。

## 用鼠标施加支承、载荷和初始条件

1. 打开 **Boundary / Initial** 页，选择支承、载荷或初始场对应的编辑页。
2. 点击 **启动物理点选（左键选中键确认）**。
3. 在三维视图用左键选择符合当前条件类型的几何；按照面板提示继续选择所需目标。
4. 在视图内用中键确认当前选择。目标会进入右侧编辑器。
5. 填写参数，点击 **Add / Update** 保存条件。中键只确认几何目标，并不自动提交条件。

初始条件和参考法向压力以曲面为目标；普通边界条件不能把 Coupling 边当作普通边界使用。其他文档、结果对象、前处理预览对象以及失效或有歧义的映射会被拒绝。

使用 **New** 清除当前编辑草稿，使用 **Remove** 删除选中的条件。按 **Esc** 或点击取消按钮可退出点选；切换页面或条件子页、关闭面板、重新导入几何、关闭文档或退出工作台也会清除临时交互并恢复临时显示。未启动点选时，中键保留正常视图导航用途。

## 用鼠标设置接口连接

1. 在 **Interfaces** 页点击 **启动接口点选流程**。
2. 左键点选第一个候选耦合面。
3. 按提示“左键点选另一个候选耦合面”，选择与其存在候选接口的第二张曲面。
4. 左键点选这两张曲面之间对应的候选耦合边；有多个候选接口时，选择需要的那一条。
5. 按提示“中键在耦合边上再次点选以确认目标”，在同一耦合边上用中键确认。
6. 在右侧设置连接类型、罚因子等参数，再点击 **Confirm Selected Interface** 保存；使用 **Exclude Selected Interface** 显式排除，或 **Reset to Candidate** 恢复待决定状态。

这个流程针对已识别的候选接口施加新的连接决策，不会凭鼠标点选任意相邻曲面就自动生成新的候选几何。普通共享边或空间接近也不能自动证明需要力学耦合。

## 材料、单位、分析域与细化

在 **Materials** 页填写材料的弹性模量、泊松比、密度和截面厚度，然后在 **Patch Assignments** 中指定材料及截面。厚度必须为正；参与分析的曲面必须有有效赋值。

| 单位体系 | 弹性模量 | 密度 | 厚度 |
| --- | --- | --- | --- |
| mm-N-s | N/mm² | tonne/mm³ | mm |
| m-N-s | Pa | kg/m³ | m |

FreeCAD 内部 CAD 长度采用毫米。切换单位下拉框只选择目标体系；点击 **Convert Values to Selected Unit System** 才执行现有数值的换算。先用 **Add / Update** 提交草稿，或用 **New** 放弃草稿。当前统一罚参数涉及转动耦合时的自动换算可能被拒绝，应按提示处理，不能假定所有罚参数均可无条件换算。

在曲面赋值表中控制曲面是否参与分析。隐藏或显示几何不会改变分析域；未参与分析的曲面可以继续显示。至少保留一张有效分析曲面，超出分析域的条件会被检查并拒绝。

在 **Groups** 中建立曲面组或边组，再把支持该组类型的条件指向组。组目标与直接几何目标不能混用；缺失成员会阻止有效导出。初始场当前使用直接曲面目标。命名组和文档关联使用明确的几何映射；改变 CAD 几何后需要重新检查和受控绑定。

可选的细化设置保存 p/q 次数及插入节点数。壳分析要求足够次数和内部连续性；升阶不能自动修复已有的 C0 不连续。预览采样密度与分析细化、积分点数量是不同设置。

## 条件、压力与时间表

支承可使用强约束或罚约束。壳的夹持设置在支持的完整自然参数边上约束相邻控制点行；不要把任意裁剪边或任意 CAD 顶点当作通用夹持目标。

载荷可使用曲面或边上的向量载荷，也可使用曲面上的标量参考法向压力。压力的正负与显式翻转共同决定方向。参考法向由参考几何的 `du × dv` 得到，不保证等于 CAD 实体的“外法向”。当前压力作用于参考构形，非线性分析也不会把它变为随动压力。

时间幅值表至少包含两个有限值点，时间严格递增；幅值按分段线性插值，作用区间之外为零。表中的时间拐点不会自动变成求解时间步，需检查时间步设置。单位换算不改变幅值和时间表。

初始速度及加速度用于动力分析；非零初始位移需要符合非线性分析要求。初始场在初始化时施加，不等同于持续固定自由度。

## 前处理预览、保存与计算

在 **Preview** 页选择支承、载荷、参数方向、参考法向及材料截面等图层，使用 **Rebuild Preview** 更新或 **Clear Preview** 清除。图形和计数用于检查输入，不是几何积分正确性或力学结果的证明。

**Save Project** 保存 `.ibra-project.json`；在 **Output** 中使用 **Save to Document** 保存文档关联数据，再保存 `.FCStd`。重新打开 FreeCAD 文档后可直接使用 **Restore Document** 恢复。几何改变会使旧绑定失效，需要按提示检查和重新绑定。

推荐计算顺序：

1. **Validate Model** 检查输入。
2. **Export Analysis Model →** 导出计算文件。
3. **Initialize Exported Model** 检查 Kratos 初始化。
4. **Run Exported Analysis** 运行计算。

导出和运行生成独立的 `ibra_case*`、`ibra_run*` 目录。初始化成功只说明初始化阶段通过；求解退出和结果图像也不能单独证明物理正确性。后端状态可在 **Output** 中检查。

## 查看计算结果

1. 在结果页选择 **Use Last Run**，或用 **Browse Run…** 指定运行目录。
2. 点击 **Load Result Metadata**。
3. 选择时间帧、位移 X/Y/Z 或模长，设置变形放大倍数。
4. 点击 **Draw Result Frame**；放大倍数为 0 时查看参考构形。使用 **Clear Result Display** 清除结果图层。

结果查看器读取 Kratos 原生 `results.vtkhdf`。显示细分只影响结果图形，不改变分析离散。当前原生输出不提供完整的 CAD 面/UV 映射。强约束的 `REACTION` 与罚约束的原始 RHS 分开标识；罚约束的物理支承反力尚不可用，不能据此宣称总体平衡已经验证。

## 预览版范围与限制

本机验证环境为 Windows x64、FreeCAD 1.1.3 及现有 Kratos 后端。版本验证覆盖三个指定算例和新增交互流程，不代表任意复杂 STEP 裁剪域都已验证。当前主要面向曲面壳与膜，不提供通用梁、实体或接触分析。候选接口仍需使用者确认连接意图；裁剪积分、求解收敛与反力平衡应结合各算例的数值检查判断。

新增鼠标流程已通过原生 FreeCAD 事件与坐标映射验证；不同导航样式、显示缩放和实际鼠标操作仍建议在当前预览环境中检查。面板拒绝操作时，应按下一步提示调整目标或输入，不要绕过几何失效保护。
