# 面向 Kratos 的 IBRA 前处理器——中文使用说明

版本：0.2.0。界面名称：**IBRA Preprocessor for Kratos**。

本工作台在 FreeCAD 中完成基于边界表示的等几何分析前处理：导入精确几何，定义材料和离散空间，施加边界条件与初始条件，并输出 Kratos 结构分析算例。界面使用专业英语；本说明的解释文字使用中文，软件名称、文件名、命令和必要的接口标识符保留原文。

## 1. 安装与启动

先按照[中文安装指南](Installation_zh.md)配置独立 Python 3.11 环境、检查依赖并安装到 FreeCAD 用户模块目录。本版本随插件携带 STEP 转换器源码，不需要原有项目目录。

安装后重启 FreeCAD，选择 **IBRA Preprocessor for Kratos**。在输出页检查后端环境。几何页提供悬臂示例打开按钮，可直接载入安装目录中的已配置模型。

面板可以拖宽、浮动和滚动。左侧导航依次对应几何、材料、细化、支承、载荷、初始条件、接口和输出。底部提供校验、导出和停止操作。后端配置保存于 FreeCAD 用户目录的 `IBRA/backend.json`；生成数据默认写入 `IBRA-work`。路径修改后需要保存后端配置。

## 2. 几何导入与实体选择

1. 点击顶部几何导入按钮，选择 `.stp` 或 `.step` 文件。
2. 如需专用转换配置，先在几何页选取配置文件，再导入。安装目录的 `examples/profiles/default.json` 提供空的默认配置。特定模型的排除规则必须逐个审查。
3. 等待后台转换。表格列出曲面片、单侧边界、双侧耦合候选及其边界表示编号。
4. 在三维视口或表格中选择曲面或边界；按住 Ctrl 可多选独立实体。
5. 进入对应条件页面，点击实体分配按钮，将当前选择写入编辑器，填写数值后添加或更新条件。

曲面按原始边界表示显示，独立边界对象使用采样折线以便选择。导出的分析几何仍为原始有理样条曲面与参数域裁剪曲线。橙色曲线仅表示几何耦合候选，不证明实际结构连接关系。

修改显示对象的形状或位置会阻止导出。请把修改后的 CAD 模型另存为 STEP，重新导入并核对条件分配。

## 3. 材料与单位

材料页可添加、删除和修改材料，包括唯一编号、名称、杨氏模量、泊松比、密度和厚度。采用各向同性线弹性平面应力本构。材料通过细化页的编号分配到曲面片。

杨氏模量、密度和厚度必须为有限正数；泊松比严格位于 −1 与 0.5 之间；材料编号必须唯一。

OCCT 导入后使用毫米坐标。

| 单位制 | 几何导出 | 杨氏模量 | 密度 | 厚度 | 线载荷 | 面载荷 |
| --- | --- | --- | --- | --- | --- | --- |
| `mm-N-s` | 保留毫米 | N/mm² | tonne/mm³ | mm | N/mm | N/mm² |
| `m-N-s` | 三维坐标乘 0.001 | Pa | kg/m³ | m | N/m | N/m² |

默认钢密度为 `7.85e-9` tonne/mm³。切换单位制只改变完整算例导出时的几何缩放，不自动换算材料、厚度、位移或载荷。所有物理量必须保持一致。仅导出几何时始终保留毫米。

## 4. 单元与离散空间

每个导入曲面片必须且只能分配一组材料和单元。

| 设置 | 含义 |
| --- | --- |
| 壳单元 | 基尔霍夫–洛夫壳；最低二阶，内部基函数连续性至少为 C¹ |
| 膜单元 | 仅描述膜作用；最低一阶，不提供壳弯曲刚度 |
| `p`、`q` | 两个参数方向的目标多项式阶次，不低于原始阶次，最大为 8 |
| `h-u`、`h-v` | 每个已有节点跨度内插入的节点数，范围为 0–100 |
| `GP` | 每跨度积分点设置；0 使用默认规则，显式设置范围为 1–20 |

批量操作时，选择目标行或全选，填写材料、单元、最低目标阶次和节点插入数，再应用到选中曲面片；已有更高阶次不会降低。

这里的细化是样条节点插入与升阶，不是传统有限元的三角形或四面体网格尺寸。已有内部 C⁰ 节点经升阶后仍为 C⁰，不能仅通过升阶满足壳的 C¹ 要求。需要有效的重新参数化或冗余节点处理；只有物理模型确实为膜时才能改用膜单元。

## 5. 本质边界条件与固支

支承页提供强施加和罚函数施加两种位移边界条件。

**强施加：**分别勾选位移分量并填写规定值；未勾选的分量不受该条件约束。选择曲面片时，可指定四条自然参数边、四个自然角点或全部控制点。选择单侧边界时，程序检查其是否完整对应自然参数边。

**相邻控制点行固支：**在完整自然参数边上，额外约束相邻控制点行，使用相同的位移分量和值。这是本版本实现壳固支的方法，不是添加独立转角自由度。角点或全部控制点选择不能使用此选项。

**罚函数施加：**用于单侧边界曲线，包括一般裁剪边。目前同时约束三个位移分量，且在整个分析时间内有效。界面自动选择三个分量，锁定时间区间，禁用相邻行固支。罚因子必须为正，应通过敏感性和条件数分析选取。

自然参数边和角点对应控制网位置，不表示任意参数坐标插值。面上顶点只有唯一匹配自然样条角点时才支持强约束；一般裁剪顶点点支承尚未实现。

## 6. 载荷与初始条件

载荷页支持常数向量和有效时间区间。

- 线载荷：选择单侧边界，输入单位长度上的力。
- 面载荷：选择曲面片，输入单位面积上的力。
- 恒定载荷：按所选几何测度积分，单位需结合目标维度解释。

有效区间必须位于分析起止时间内；`End` 表示分析结束时刻。区间外显式清零载荷。当前不提供任意空间函数或时间历程表达式。

初始位移、速度和加速度按整个曲面片的全部控制点设置，只在初始化时施加一次，不固定自由度。速度和加速度需要动力分析；非零初始位移需要非线性分析。

双击已有条件可修改；新建按钮退出当前编辑模式；删除按钮移除选中条目。保存项目之前，先将表单修改提交到条件列表。

## 7. 曲面片耦合

耦合页显示两侧曲面片编号，可启停接口、设置罚因子和转角连续性。仅位移耦合不保证完整的壳弯曲连续性；连续壳连接应按物理意图启用转角耦合。转角耦合要求两侧均采用壳单元。

必须结合真实连接方式审查自动检测结果。罚因子不是通用材料常数，需要验证其对解和数值条件的影响。

## 8. 校验、导出与求解

1. 在输出页选择静力或隐式动力分析，以及线性或非线性方案。
2. 输入开始时间、结束时间和正的时间步。时间步不能超过总分析时长。
3. 按需启用位移可视化输出。显示细分范围为 1–100，与分析空间细化无关。
4. 点击模型校验，查看错误和提示。修正错误后才能导出。
5. 点击算例导出并选择父目录，程序创建唯一的 `ibra_case_*` 子目录。
6. 在输出页初始化最近导出的模型，再运行分析。日志位于工作目录的 `jobs` 文件夹。

| 文件 | 用途 |
| --- | --- |
| `geometry.cad.json` | 精确曲面、裁剪边界与耦合拓扑 |
| `refinements.iga.json` | 节点插入和升阶参数 |
| `physics.iga.json` | 几何到单元、条件和子模型的映射 |
| `Materials.json` | 本构、材料、厚度和罚因子 |
| `ProjectParameters.json` | 模型构造、求解器、过程和输出 |
| `MainKratos.py` | 结构分析入口 |
| `ibra_case_process.py` | 初始场与有效区间载荷过程 |
| `project.ibra-project.json` | 可重新编辑的项目快照 |
| `export_report.json` | 单位、提示、校验和与运行版本 |

`.iga.json` 扩展名及 Kratos 的应用、单元和模型构造器标识符属于后端接口，保留原名以保证兼容。单独的 CAD 文件不能代替完整分析模型。

完整算例可以脱离 FreeCAD 运行，但需要后端依赖。从下载的仓库根目录执行，并将以下目录名替换为实际导出目录：

```powershell
& '.\.venv\Scripts\python.exe' '.\ibra_case_example\MainKratos.py' --check
& '.\.venv\Scripts\python.exe' '.\ibra_case_example\MainKratos.py'
```

初始化检查不能证明约束充分或求解收敛。计算成功不代替离散空间、罚因子和工程收敛分析。

## 9. 保存与重开

项目保存按钮写出 `.ibra-project.json`。重开时重新转换原始 STEP，并检查源文件和转换几何校验和。旧 `.iga-project.json` 可通过打开对话框的通用项目 JSON 筛选选择。

分析项目与 FreeCAD 文档不同；仅保存 `.FCStd` 不能保存全部分析设置。项目引用的 STEP、配置和后端路径须保持有效。项目尽可能保存相对于项目文件的源文件路径。迁移时一起移动源文件，或修改对应引用；不能绕过几何变化校验复用旧条件。

## 10. 示例与适用范围

悬臂壳示例长 10 mm、宽 1 mm、厚 0.1 mm，杨氏模量 200000 N/mm²，泊松比 0；根部固支，端线载荷 −0.001 N/mm。端位移解析值为 −0.02 mm，已验证计算位移绝对值约为 0.0200000000008 mm。

双曲面片悬臂壳采用位移与转角耦合，位移绝对值约为 0.0200000031 mm，相对解析误差约为 1.56×10⁻⁷。原两曲面片文件完成膜分析。机翼仅验证了 22 个曲面片和 81 条耦合的转换与索引，未验证结构求解。

本版本不含独立梁或索、体积参数化、实体单元、接触、多物理场耦合、一般裁剪点支承、任意时空表达式或结果场回显。Kratos 10.4.3 可视化采样背景曲面，孔洞与裁剪显示需独立核实，不能据显示网格判断积分域。重复求解同一目录可能追加可视化时间数据，建议重新导出到独立目录。

可复现测试位于仓库的 `tests`，安装目录的 `examples/cantilever` 包含 STEP 和相对路径项目。验证记录见 `Validation.md`。历史机翼模型不在本次分发范围内。
